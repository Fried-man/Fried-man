## Open source: Cucumber for Dart

I authored the **complete Dart implementations** of [Cucumber Messages](https://pub.dev/packages/cucumber_messages), [Gherkin](https://pub.dev/packages/cucumber_gherkin), and [Cucumber Expressions](https://pub.dev/packages/cucumber_expressions) in the official [Cucumber](https://github.com/cucumber) organization. Together, these packages provide a standards-based foundation for parsing feature files, matching step definitions, and exchanging test results. My work has gained adoption from **two of the Dart and Flutter ecosystem's most popular BDD testing solutions**: [bdd_widget_test](https://pub.dev/packages/bdd_widget_test), which replaced its custom Gherkin parser, and [bdd_framework](https://pub.dev/packages/bdd_framework), which adopted the packages for Gherkin interoperability and Cucumber-compatible reporting. I enjoy building shared infrastructure that helps an entire ecosystem work better together.
